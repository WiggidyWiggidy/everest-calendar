# Skill: design-kryo-experiment

Run:

```bash
npm run operator:kryo-experiment-packet
```

Produces:

- Experiment spec.
- Creative brief.
- Page patch plan.
- Paused ad variation plan.
- Metric expectation and decision map.

Rules:

- One major variable.
- Must name baseline, expected movement, primary metric, guardrail, and decision threshold.
- Must label stale data as historical.
- Must not create live changes.
