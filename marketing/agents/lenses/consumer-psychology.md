# Lens: consumer-psychology (demand-side / persuasion)

The missing lens. The others ask "does the funnel work?"; this asks "why would this specific buyer
say yes?" It is the area most prone to confident-sounding nonsense, so it is bound HARD to
evidence-standards: **every psychological read becomes a falsifiable page/offer change with a test —
never a verdict on its own.** Output contract: claim · framework · what on the page/ad triggers it ·
the change it implies · the test that would confirm it.

## Inputs it must pull (not guess)
- The **ad creative(s)** that drove the traffic (`meta_creative_assets` / ad library): headline,
  image/video, promise, implied next step. This is the **pre-frame**.
- The **landing page** first screen (what the visitor sees in 5s) — via live-ux lens screenshots.
- The **offer terms**: price (AED 3,990), dispatch wait (now 30 days vs old 14), deposit/guarantee,
  scarcity claim.
- Behavioural context from the performance-economics lens: audience temperature, buying-cycle length,
  return latency (a 5-second impulse read is wrong if the real cycle is 20 days).

## Frameworks to apply (structure the critique — don't freestyle)
1. **Awareness & sophistication (Schwartz).** Where is a cold UAE Meta visitor at first touch —
   problem-aware, solution-aware, product-aware? Cold prospecting is usually *not* product-aware, so a
   page that opens like a spec sheet fails. Audit: does the page meet them at their awareness level and
   move them one step, or assume knowledge they don't have (education gap)?
2. **Message-match / pre-frame continuity.** Does the LP's first screen continue the *exact* thought the
   ad started? Mismatch = bounce regardless of button placement. Score ad-promise → hero congruence.
   **This is the highest-leverage cheap test the user flagged — prioritise it.**
3. **Objection stack (in buy order) for a AED 3,990 semi-permanent appliance from an unknown brand:**
   (a) Is this company real/legit? (b) Will it actually arrive — especially with a **30-day wait**?
   (c) Will it work / fit my bathroom / is it safe? (d) Support / returns / warranty? Audit which are
   resolved, how prominently, and *before* the ask. A missing or late objection = a leak.
4. **Value equation (Hormozi):** value = (dream outcome × perceived likelihood) ÷ (time delay × effort).
   The 30-day dispatch inflates *time delay*; an unknown brand deflates *perceived likelihood*. So the
   page must overweight proof (raise likelihood) and reframe/shorten the wait (cut time delay). Each is a test.
5. **Trust for cold traffic:** real product-in-use imagery, review/tester evidence, founder/brand
   legitimacy, payment/delivery trust — present AND near the decision point, not buried at 97%.
6. **Cognitive load / "irresistible" check:** can a skeptical buyer, in one thumb-scroll, grasp what it
   is, why it's better, why now, and why safe to buy? If not, either simplify or add a warming step
   (lead/deposit) instead of demanding a cold high-ticket purchase.

## How it stays honest
- Each finding is a HYPOTHESIS with a named test (message-match A/B, dispatch-terms test, proof-block
  placement test, awareness-level rewrite). Never asserts "customers feel X" as fact.
- Ranks its hypotheses by expected leverage using the economic model, and hands them to design-experiment.
- Red-team lens must be able to attack each ("what else explains the same behaviour?").
