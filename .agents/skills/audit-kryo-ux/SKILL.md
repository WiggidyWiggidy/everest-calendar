# Audit KRYO UX

Primary viewport: 390x844. Also inspect 320, 375, 430 and desktop when practical.

For each critical screen ask:
1. Can the target customer understand the value/action in <3 seconds?
2. Is the dominant CTA visible, clear and easy to tap?
3. Is mobile hierarchy correct before desktop polish?
4. Are there duplicate forms, gates, support widgets or competing actions?
5. Does the user retain state/resume where expected?
6. Are tap targets, spacing, keyboard behavior, sticky elements and safe areas usable?
7. Does the page preserve message match with the ad/experiment treatment?
8. Does cart/variant/checkout behavior match the intended flow?
9. Are claims, scarcity, delivery and price treatments credible and internally consistent?
10. Is the page technically working but still cognitively difficult?

Capture rendered evidence/screenshots. Return PASS or FAIL with exact screen, viewport, observed behavior, customer impact and required correction. Do not edit the implementation you review.
